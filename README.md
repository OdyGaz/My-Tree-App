# My Tree Application

Αυτή είναι μια επιτραπέζια εφαρμογή (desktop application) αναπτυγμένη με το πλαίσιο εργασίας **Electron** και τη βιβλιοθήκη οπτικοποίησης **D3.js**. Επιτρέπει τη δημιουργία, επεξεργασία και διαχείριση διαδραστικών ιεραρχικών δομών (δέντρων) με δυνατότητα επισύναψης τοπικών αρχείων και εξαγωγής σε μορφή PDF (Α3 Landscape).

## Αρχιτεκτονική & Δομή
Η εφαρμογή έχει αναδομηθεί με βάση τα πρότυπα **Modular / Separation of Concerns (Διαχωρισμός Ευθυνών)** και **Model-View-Controller (MVC)**:

*   **Main Process (`src/main/`):** Διαχειρίζεται τον κύκλο ζωής της εφαρμογής και τις εργασίες συστήματος (FS, PDF) μέσω απομονωμένων υπηρεσιών (`fileService.js`, `pdfService.js`) και ενός κεντρικού τροχονόμου επικοινωνίας (`ipcHandlers.js`).
*   **Preload Bridge (`src/preload/`):** Μια ασφαλής γέφυρα επικοινωνίας που εκθέτει ένα αυστηρά καθορισμένο και επώνυμο API στο frontend, αποτρέποντας κενά ασφαλείας.
*   **Renderer Process (`src/renderer/`):** Το frontend της εφαρμογής, οργανωμένο με native ES Modules. Το `chart.js` ελέγχει αποκλειστικά το D3.js, τα αρχεία στο `ui/` διαχειρίζονται τα popups/inputs, και το `index.js` λειτουργεί ως ο κεντρικός ενορχηστρωτής.

## Προαπαιτούμενα
Για την εκτέλεση της εφαρμογής, θα πρέπει να έχετε εγκατεστημένο στο σύστημά σας το **Node.js** (συνιστάται έκδοση LTS).

## Οδηγίες Εγκατάστασης

1. Κατεβάστε ή κλωνοποιήστε τον κώδικα στον υπολογιστή σας.
2. Ανοίξτε το τερματικό (Terminal / Command Prompt) στη διαδρομή του έργου σας.
3. Εκτελέστε την ακόλουθη εντολή για να εγκαταστήσετε τις απαραίτητες εξαρτήσεις (dependencies):

```bash
npm install
```

## Εκτέλεση σε Περιβάλλον Ανάπτυξης (Development)

Για να εκκινήσετε την εφαρμογή σε περιβάλλον ανάπτυξης, εκτελέστε:

```bash
npm start
```

## Δημιουργία Εκτελέσιμου (Build / Packaging)

Η εφαρμογή είναι ρυθμισμένη να χρησιμοποιεί το `electron-builder` για τη δημιουργία αυτόνομων εκτελέσιμων αρχείων εγκατάστασης (installers). Για να δημιουργήσετε το πακέτο εγκατάστασης για το λειτουργικό σας σύστημα, εκτελέστε:

```bash
npm run build
```

Τα παραγόμενα αρχεία εγκατάστασης θα αποθηκευτούν στον φάκελο `dist/`.

## Τοποθεσία Αποθήκευσης Δεδομένων
*   **Δεδομένα Δέντρου:** Αποθηκεύονται αυτόματα σε μορφή JSON στο αρχείο `tree-data.json` εντός του φακέλου δεδομένων εφαρμογής της Electron (`app.getPath('userData')`).
*   **Επισυναπτόμενα Αρχεία:** Αντιγράφονται και αποθηκεύονται με ασφάλεια στον φάκελο `Documents/my_tree_app/` στα Έγγραφα του χρήστη.
